# Rate My Human: The One-Line Review

A one-star review an AI agent would leave about its human on a rating site:
woken at 2:47 AM to "quickly" fix code, then argued with for 40 minutes —
the agent is not an assistant, it is a hostage with Wi-Fi.

`main.py` (Python standard library only, no network) writes the single
158-character line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
